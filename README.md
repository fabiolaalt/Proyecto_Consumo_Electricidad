# Análisis de datos del sistema eléctrico – Sesión 03

## Descripción

Proyecto de análisis de datos sobre el sistema eléctrico, cuyo objetivo es estudiar la demanda y generación eléctrica y su relación con variables meteorológicas y temporales.

## Contenido del proyecto

El proyecto incluye:

- **Data:** base de datos SQLite (`electricidad.db`) y archivo Excel (`electricidad_para_panel.xlsx`) con los datos utilizados.
- **Notebooks:** cuaderno Jupyter con los ejercicios y análisis realizados en Python, además de una visualización HTML.
- **Docs:** documento PDF con las instrucciones de la prueba individual.

## Análisis realizados

- Evolución de la demanda eléctrica y comparación entre días laborables y de descanso.
- Identificación de los meses con mayor y menor demanda.
- Relación entre temperatura y demanda eléctrica.
- Análisis de la generación solar fotovoltaica.
- Estudio de los días de lluvia por ciudad.
- Consultas SQL y elaboración de gráficos e indicadores.

## Tecnologías utilizadas

- Python y Jupyter Notebook.
- pandas, Matplotlib y Seaborn.
- SQL y SQLite.
- Excel.
- HTML y CSS.

## Objetivo

Aplicar herramientas de análisis y visualización de datos para transformar información del sistema eléctrico en resultados comprensibles y útiles.
